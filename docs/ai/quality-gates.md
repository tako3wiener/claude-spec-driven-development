# v5 品質ゲートと承認方式

詳細手順・署名例・外部隔離条件は **`docs/ai/v5-operations.md`** を参照。

| Gate | 判定主体 | 完了条件 | NGの場合 |
|---|---|---|---|
| G0 | 人＋セットアップツール | Gitルート/対象Javaモジュール/テスト環境/コマンド確定、`project_setup.py check`成功 | BLOCKED |
| G1 | AI、レビュー | 要件ID/原本出典/既存影響、C/Dの仕様不足、受入条件、テストケースを実装前に確定 | G2へ進めない |
| **G2** | **人が外部署名** | G2 JSON署名の検証に成功、REQ/TC/変更計画/設定の4ハッシュ一致 | **実装禁止** |
| G3 | AI、開発中テスト | Java実装、単体/結合を部分実行→修正、既存機能の回帰 | 必要なら自動修正 |
| **G4** | AI＋外部環境責任者 | NET署名＋実ネットワーク隔離、正式Playwright Java/JUnit、0件/skipなし、PNG/Trace/run ID一致 | FAILまたはBLOCKED |
| G5 | 独立AIレビュー | REQと実コード/TC/実行証跡の対応、重大未解決事項ゼロ。**ローカルPASSは独立証拠でない** | 是正・再実行 |
| **G6** | **人が外部署名** | `summary.json`=PASS、G6署名がRUN_ID/snapshot/summaryのSHAに一致 | マージ不可 |

## dev / finalの厳密な区別
- **dev:** 部分テスト・一時的なフィルタ可。開発速度重視。devの成功はG4のPASSに使用不可。
- **final:** 承認済みE2Eシナリオ全件、新しいRUN、単一専用JUnit領域、結果の実件数確認、エビデンス必須。`-DskipTests`、`maven.test.skip`、`-x test`、`--tests`などは拒否。
- **DEMO_ONLY:** `examples/playwright-java`は資料・挙動確認専用。G4の正式PASSに用いない。

## 必須の追加人間承認
DB削除・本番権限・認証や公開APIの変更、依存追加/解決/インストール、G2後のスコープ/期待結果変更、NET環境変更やTrace保存ポリシー変更。新しい操作で既存ユーザー/第三者へ影響があれば停止する。

## 限界
G2/G6 JSONの署名は**秘密鍵がClaudeの届かない場所にあり、公開鍵・Hook・実行ポリシーが外部OS権限で保護されている**ことを前提とする。NET署名は実際のFW設定を検査しない。R12のCI強制・ブランチ保護は保留。PNG/Trace/JSONの整合確認のみでは実行の独立証明や業務仕様の正しさを保証できない。
